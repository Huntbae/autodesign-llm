## 세 버전의 관계 (요약)

```
v1 로컬 LLM        →  v2 로컬+RAG 하이브리드  →  v3 클라우드
(IP보안·오프라인)     (★주력: 보안+도메인정확도)    (성능·확장성·빠른개발)
   기반 엔진             지식 레이어 추가              규모/시뮬 확장
```

- **공통 코어**(요구사항 파서·형상 생성·검증 파이프라인)는 세 버전이 공유한다.
- 세 버전은 **LLM 추론 위치**와 **지식/연산 자원**의 배치만 다르다.
- 권장 전략: **v2(하이브리드)를 주력 제품**으로 삼고, v1은 그 부분집합,
  v3는 무거운 시뮬(CFD/위상최적화) 버스트용으로 위치.

## 핵심 원칙
1. **검증 게이트 우선** — 생성보다 검증이 제품의 가치다.
2. **출처 추적** — 모든 물성·표준 수치는 검증된 출처로만.
3. **안전 고지** — 최종 양산 판정은 정식 CAE·실물시험 필수. 시스템은 보조.
4. **추상화로 이식성 확보** — LLM/지식/연산 백엔드를 인터페이스로 분리해
   세 버전 간 전환 비용을 최소화.
